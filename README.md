# Видео-плеер

Кастомный видео-плеер с панелью управления: воспроизведение/пауза, регулировка громкости, полоса прогресса с интерактивным кружком и полноэкранный режим.

## Как установить

**Требуется:** браузер и редактор кода.

1. Откройте `index.html` в браузере — плеер готов к работе.

**Для разработки с автообновлением:**

```bash
# Установите зависимости
pip install livereload

# Запустите сервер разработки
python server.py
```

Сервер запустится на порту `5501` с поддержкой LiveReload.

## Как выглядит плеер

**Основные элементы управления:**
- Кнопка воспроизведения/паузы
- Регулятор громкости
- Отображение текущего времени и длительности видео
- Полоса прогресса с интерактивным кружком
- Кнопка полноэкранного режима

**Особенности:**
- Кружок на полосе прогресса скрыт по умолчанию
- При наведении на полосу кружок появляется с плавной анимацией (opacity)
- Перетаскивание кружка позволяет быстро переходить по видео
- Адаптивный интерфейс с темной панелью управления

## Как использовать

```html
<!-- Подключите скрипты в конце <body> -->
<script src="https://code.jquery.com/jquery-3.4.1.min.js"></script>
<script src="https://unpkg.com/playable@2.10.3/dist/statics/playable.bundle.min.js"></script>
<script src="player.js"></script>

<!-- Инициализация плеера -->
<script>
createPlayer({ 
    elementId: 'player',
    src: 'ссылка_на_видео.mp4'  // опционально
});
</script>
```

## Функциональность

### Кнопки управления
- **Play/Pause** — воспроизведение и пауза видео
- **Volume** — регулировка громкости (0-100%)
- **Mute** — полное отключение звука
- **Fullscreen** — переход в полноэкранный режим

### Прогресс-бар
- **Клик по полосе** — переход к нужной позиции
- **Перетаскивание кружка** — плавное переключение по видео
- **Hover-эффект** — кружок появляется при наведении с плавной анимацией

### Таймер
- Отображение текущего времени в формате `HH:MM:SS`
- Отображение общей длительности видео

## Кастомизация

- **Видео**: измените `src` в `createPlayer()` или передайте при инициализации.
- **Размеры**: отредактируйте `.vp-player` ширину и высоту в `index.html` (сейчас 800x600px).
- **Цвета**: отредактируйте цвета в CSS:
  - `#d9534f` — основная полоса прогресса
  - `#ff2d55` — кружок прогресса
  - `rgba(0,0,0,0.65)` — фон панели управления
- **Кнопки**: в `player.js` можно добавить новые обработчики событий в функции `activate*()`.
- **Шрифт**: используется Google Fonts Rubik, можно заменить в CSS.
